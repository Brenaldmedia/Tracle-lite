# 🚀 INSTALLATION

## 1️⃣ CLONE REPOSITORY

```bash
git clone https://github.com/Brenaldmedia/Tracle-Lite.git
cd Tracle-Lite
2️⃣ INSTALL DEPENDENCIES
npm install
3️⃣ CREATE .env

Create:

.env

Add:

SESSION_ID=Tracle_xxxxxxxxxxxx
PREFIX=.
BOT_NAME=TRACLE-LITE
OWNER_NUMBER=234xxxxxxxxxx
   ```
4️⃣ START BOT
npm start

Development mode:

npm run dev
